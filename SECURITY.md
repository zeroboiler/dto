# Security Policy

## Reporting Vulnerabilities

If you discover a security vulnerability within ZeroBoiler DTO, please send an email to
[security@zeroboiler.dev](mailto:security@zeroboiler.dev). All security vulnerabilities will be promptly addressed.

Please do **not** publicly disclose the vulnerability until it has been resolved.

## Supported Versions

Only the latest version of this package receives security updates.

| Version | Supported |
| ------- | --------- |
| 1.x     | ✅        |
